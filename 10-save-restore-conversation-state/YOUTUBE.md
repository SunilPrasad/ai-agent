## Title

Save and Restore AgentSession State in C#

## Description

Keep a Microsoft Agent Framework conversation across process boundaries. This focused C# example serializes an `AgentSession` to JSON, writes it to a demonstration file, restores it through the same agent, and verifies that a follow-up remembers the earlier trip preference.

Prerequisites: sessions 1–9, .NET 10, `OPENROUTER_API_KEY`, and `OPENROUTER_MODEL`.

The file is deliberately simple; production session snapshots require access control, secure storage, encryption, and trusted user-to-session mapping.
