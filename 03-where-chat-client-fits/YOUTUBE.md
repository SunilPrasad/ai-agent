## Title

Microsoft Agent Framework C# — Where Does IChatClient Fit?

## Description

`OpenAIClient`, `ChatClient`, `IChatClient`, and `ChatClientAgent` sound similar, but each belongs to a different layer.

In Video 03, we expand one C# example into separate variables and follow a request from Microsoft Agent Framework through Microsoft.Extensions.AI, the OpenAI .NET SDK, and the external OpenRouter service. You will learn which layer owns endpoint configuration, which type is provider-neutral, and where the agent begins.

Prerequisites: Videos 01–02, .NET 10, and OpenRouter configuration in `OPENROUTER_API_KEY` and `OPENROUTER_MODEL`.

Next: use agent instructions to change behavior without changing the chat-client pipeline.
