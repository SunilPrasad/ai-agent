## Final title

Microsoft Agent Framework Structured Responses: One Typed C# Result

## Description

Free-form model text can be excellent for a person and still be a brittle contract for a .NET application. This lesson compares an ordinary `AgentResponse.Text` with one structured `AgentResponse<TripPlan>` and shows how `RunAsync<TripPlan>` gives C# code properties it can count, compare, and display without parsing generated prose.

The example uses Microsoft Agent Framework, Microsoft.Extensions.AI, the OpenAI .NET SDK, and OpenRouter's OpenAI-compatible endpoint. You need .NET 10, `OPENROUTER_API_KEY`, `OPENROUTER_MODEL`, and a selected model that supports structured output. The next lesson handles invalid or unacceptable structured output.
