## Title

Microsoft Agent Framework Function Tools in One C# Example

## Description

Learn the complete Microsoft Agent Framework function-tool flow in one C# lesson. We turn ordinary methods into tools, follow model arguments into typed C# parameters, return results to the model, let the model choose between tools, represent an expected failure clearly, and expose a focused agent as a tool.

The example builds one OpenRouter-backed travel assistant with fixed demonstration weather, currency conversion, travel-time, and packing-specialist tools. Console tracing makes every ordinary C# tool invocation and received parameter visible; the specialist contributes its returned text through the same outer tool loop.

Prerequisites: sessions 1–10, .NET 10, `OPENROUTER_API_KEY`, `OPENROUTER_MODEL`, and a model with function-calling support.

Next: request typed structured responses from an agent.
