## Title

Continue an Agent Conversation with AgentSession in C#

## Description

Learn how a Microsoft Agent Framework `AgentSession` makes a follow-up prompt part of the same conversation. The C# example sends two related turns through OpenRouter while avoiding manual transcript reconstruction.

Prerequisites: sessions 1–7, .NET 10, `OPENROUTER_API_KEY`, and `OPENROUTER_MODEL`.
