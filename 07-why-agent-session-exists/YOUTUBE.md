## Title

Why AgentSession Exists in Microsoft Agent Framework

## Description

One agent can serve many conversations, but each conversation needs its own state. This lesson separates the reusable Microsoft Agent Framework `AIAgent` from an `AgentSession`, then builds a minimal C# console example using OpenRouter.

Prerequisites: sessions 1–6, .NET 10, and the `OPENROUTER_API_KEY` and `OPENROUTER_MODEL` environment variables.

Next: reuse the same session across related turns.
