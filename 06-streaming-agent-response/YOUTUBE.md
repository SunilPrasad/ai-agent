## Title

Microsoft Agent Framework C# — Stream Responses with await foreach

## Description

Make an agent response appear as it is generated instead of waiting for the whole answer.

Video 06 uses Microsoft Agent Framework's `RunStreamingAsync`, .NET's `await foreach`, and `AgentResponseUpdate.Text` to print an OpenRouter-backed response progressively. You will learn the difference between `AgentResponse` and `AgentResponseUpdate`, what an asynchronous stream returns, and why update boundaries must not be treated as words or sentences.

Prerequisites: Videos 01–05, .NET 10, `OPENROUTER_API_KEY`, and `OPENROUTER_MODEL`.

Next: understand why an agent session represents one conversation.
