## Title

Microsoft Agent Framework C# — Agent Instructions Explained

## Description

What is the difference between an agent's instructions and the user's prompt?

Video 04 uses two Microsoft Agent Framework agents, one OpenRouter-backed `IChatClient`, and one identical question. Only the instructions change. You will see how stable instructions shape response style, where Agent Framework stores them, and why instructions should not contain the current task or secrets.

Prerequisites: Videos 01–03, .NET 10, `OPENROUTER_API_KEY`, and `OPENROUTER_MODEL`.

Next: create an explicit `ChatMessage` and inspect `AgentResponse`.
